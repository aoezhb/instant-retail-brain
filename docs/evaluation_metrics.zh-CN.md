# 评估指标口径

评估层将预测质量与经营结果分开记录。每次报告应同时记录数据集版本、模型版本、策略版本和评估窗口。

| 指标 | 定义 | 用途 |
|---|---|---|
| MAE | 平均绝对预测误差 | 平均单位误差 |
| RMSE | 均方根误差 | 放大较大的预测偏差 |
| WAPE | 绝对误差之和 / 实际需求之和 | 跨规模比较误差 |
| P50 覆盖率 | 实际值不超过 P50 的比例 | 中位数校准检查 |
| P90 覆盖率 | 实际值不超过 P90 的比例 | 服务水平校准检查 |
| 缺货率 | 1 - 服务率 | 回放中的缺货结果风险 |
| 库存周转 | 服务量 / 平均库存 | 资金效率代理指标 |
| 平均库存 | 评估期间持有的平均库存 | 营运资金暴露 |
| 订单金额 | 已接受决策的预计金额之和 | 采购资金承诺 |
| 执行器拒绝率 | 被拒决策数 / 决策总数 | 约束、审批、过期及执行检查的综合拒绝信号 |
| 需审批率 | 需要审批的决策数 / 决策总数 | 人工控制工作量 |

当前参考实现使用确定性合成数据和简化回放。客户项目必须先明确评估窗口、退货/取消处理、丢失销售口径、库存计价和审批分母，再比较不同运行结果。

当前 Demo 将每个商品的预测日需求率与留出窗口中的实际日均需求进行比较。生产评估应按每个预测起点、预测步长和商品分别计分后再聚合；这里的指标只是紧凑的数据契约示例，不是完整的概率校准研究。
